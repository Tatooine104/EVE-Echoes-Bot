# 🛸 EVE Echoes Automation Bot

Программный комплекс для автоматизации рутинных операций и многопоточного управления аккаунтами в мобильной MMORPG **EVE Echoes**.

---

## 💻 Системные требования и окружение

Бот разработан для запуска на операционных системах семейства **Windows** и взаимодействует с игрой через Android-эмуляторы.

- **Поддерживаемые эмуляторы:** 
	- **BlueStacks 5** *(Оптимизировано под разрешение 1280x720)*.
- **Взаимодействие:** Прямое управление эмулятором через фоновые команды `ADB (Android Debug Bridge)` и анализ графического интерфейса с помощью `OpenCV`.
- *Примечание:* Работа с другими эмуляторами *(LDPlayer, Nox и т.п.)* на текущий момент не тестировалась и официально не поддерживается.

## 🛠 Архитектурные особенности

- **Thread-Safe Очередь задач:** Каждое окно имеет собственный независимый стек задач (`TaskQueue`), управляемый потокобезопасными блокировками (`lock`).
- **Умная кросс-аккаунт паника:** При обнаружении врага одним окном (например, скаутом `localwatcher`), сигнал тревоги мгновенно передается всем активным ботам в этой же звездной системе, принудительно очищая их текущую рутину и отправляя на безопасную станцию.
- **State Persistence (DTO):** Состояние каждого аккаунта (текущая задача, статистика срабатываний триггеров, общее время работы, локация `InSpace`) автоматически сериализуется в JSON-файлы для бесшовного восстановления работы после перезапуска.

## ⚙️ Настройка конфигурации (`config.json`)

Управление аккаунтами и привязка к окнам эмуляторов осуществляется через единый конфигурационный файл. Каждое окно описывается как отдельный элемент в массиве `Accounts`.

### Пример файла конфигурации:
```json
{
  "Accounts": [
    {
      "Name": "AccountName",
      "WindowTitle": "BlueStacks_EVE.01",
      "Script": "LocalWatcher",
      "AdbPort": 5565,
      "PlanetMining": true,
      "POS": false,
      "WindowSettings": {
        "TargetWidth": 1280,
        "TargetHeight": 720
      }
    }
  ]
}
```

### Описание параметров конфигурации:

- **`Name`** `(string)` — Уникальное внутрисистемное имя персонажа/аккаунта (используется для логирования и файлов статистики).
- **`WindowTitle`** `(string)` — Точное имя заголовка окна эмулятора Windows для поиска дескриптора (`Hwnd`) и снятия скриншотов.
- **`Script`** `(string)` — Имя исполняемого сценария (например, `LocalWatcher`, `LowMiner`). Регистр строки не важен.
- **`AdbPort`** `(int)` — Уникальный TCP-порт отладки ADB для данного эмулятора (например, `5565`), позволяющий разделять клики по окнам.
- **`PlanetMining`** `(bool)` — Флаг сбора планетарных ресурсов. Если `true`, бот будет периодически заходить в меню планет для сбора и перезапуска добычи.
- **`POS`** `(bool)` — Наличие собственной структуры *(ПОС)*. Если `true`, бот может использовать его как альтернативную точку для безопасного отстоя или разгрузки руды, и для автоматического сбора планетарных ресурсов.
- **`WindowSettings`** `(object)` — Геометрические параметры игрового интерфейса для масштабирования кликов:
  - `TargetWidth` — Целевая ширина окна (стандарт: `1280`).
  - `TargetHeight` — Целевая высота окна (стандарт: `720`).

## 📈 История версий

### v.0.01.001 Глобальный рефакторинг и оптимизация архитектуры
- 🧱 **Архитектурная изоляция ресурсов:** Проведена полная очистка корня проекта. Все служебные модули, структуры и нативные зависимости перенесены в изолированное пространство имен `EVEEchoesBot.resources`, сделав проект модульным и удобным для поддержки.
- 🪵 **Строгая типизация логгера:** Текстовые маркеры категорий логов полностью заменены на строго типизированное перечисление `LogType`. Это исключило риск скрытых ошибок из-за опечаток в строках и обеспечило автодополнение кода в IDE.
- ⚙️ **Оптимизация работы с ADB и путями:** Логика автоматического копирования кликера `adb.exe` и связанных DLL перенастроена в `.csproj` на целевую подпапку ресурсов. Все внутренние пути в коде скорректированы, что гарантирует стабильный запуск ADB-сервера и развертывание инженерной сетки в релизных сборках.
- 🔒 **Потокобезопасность нового поколения:** Внедрен современный высокоэффективный тип блокировки `System.Threading.Lock` (.NET 9 / C# 13) для синхронизации глобального состояния безопасности `SystemSafetyManager`. Тяжелые дисковые операции сохранения статистики `SaveStats` вынесены за пределы критических секций `lock` для минимизации задержек в параллельных потоках.
- 🛸 **Интеграция Source Generators для WinAPI:** Класс низкоуровневого взаимодействия с ОС `WinAPI` переведен на современный атрибут `[LibraryImport]` со сквозной кодогенерацией маршаллинга. Настроен явный Юникод-маппинг (`GetWindowTextW`) для безошибочной работы с кириллическими заголовками окон.
- 📸 **Экстренная фиксация состояния (Дамп по F10):** В фоновый поток перехвата клавиш добавлена логика `ConsoleKey.F10`. При нажатии система выполняет каскадный захват скриншотов со всех активных эмуляторов, принудительно сохраняет их в `DebugScreenshots` для последующего анализа и запускает процедуру безопасной остановки.
- 🖱️ **Методы расширения UI-макросов:** Логика упаковки и распаковки двумерных координат векторов клика `(X, Y)` вынесена в оптимизированный метод расширения `ClickTo(this ActiveBotAccount bot, GameUi element)`, что упростило написание и чтение будущих игровых сценариев.
- 📝 **Индустриальное документирование:** Вся кодовая база проекта, включая нативные методы Windows, DTO-модели и перечисления задач, снабжена исчерпывающими XML-комментариями `///` для генерации сквозной технической документации.

### v.0.01.000 Базовый каркас безопасности
- **Многопоточное ядро:** Реализована асинхронная архитектура `RunLoopAsync` для параллельной работы с несколькими аккаунтами. *(Текущие тесты проводились в однооконном режиме)*.
- **Диспетчер очередей:** Внедрена динамическая система управления задачами `AccountTask`. Состав и порядок действий автоматически запрашиваются у фабрики сценариев `ScenarioFactory`.
- **Глобальный модуль защиты:** Реализован алгоритм сквозного контроля безопасности. При панике боты прерывают текущую логику, выполняют команду экстренного отварпа и докаются на станцию.
- **Релиз скрипта LocalWatcher:** Полноценно запущен сценарий «Глаз». Бот успешно распознает маркеры отношений стендингов, контролирует интерфейс чата и использует быстрый ввод для оповещения альянса.
